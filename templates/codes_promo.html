Comment ça marche. Le praticien tape le code sur le formulaire d'inscription — celui qu'ouvrent les boutons du site — et voit aussitôt son prix réduit. À la reprise de sa demande, DFM arrête ce prix sur sa fiche : convention, facture, mails et relances l'utilisent tout seuls, avec la remise et le code écrits en toutes lettres.
Paiement par carte : le lien Stripe d'une session encaisse son tarif plein. Il n'est donc pas proposé à qui a une remise — le virement reste — sauf si vous avez créé le même code dans Stripe et coché la case correspondante.
Un code ne s'efface pas, il se désactive : les inscriptions déjà faites gardent leur remise, et le journal garde la trace.
