Une adresse d'abord

DFM ne sait pas encore d'où partiront vos mails. Renseignez l'adresse de contact de cet organisme dans la section Coordonnées, plus haut sur cette page, puis enregistrez.

C'est l'adresse que vos participants verront comme expéditeur, et celle avec laquelle DFM se connectera pour envoyer. Prenez celle de l'organisme, pas une adresse personnelle : elle figurera sur chaque convention et chaque facture.

Une fois enregistrée, revenez ici : DFM saura vous dire quoi faire selon votre fournisseur.
{% elif envoi.f.special == 'google' %}
Votre adresse est chez Google — cinq minutes
  1. Ouvrez la page des mots de passe. Cliquez ici — elle s'ouvre dans un nouvel onglet, celui-ci reste ouvert.
  2. Vérifiez que vous êtes sur le bon compte.
    Tout en haut à droite de la page Google, il y a une pastille ronde : une photo, une lettre ou un logo. C'est le compte sur lequel vous êtes.
    • Elle correspond à {{ envoi.adresse }} → continuez.
    • Ce n'est pas le bon → cliquez sur la pastille, puis « Ajouter un compte » ou choisissez {{ envoi.adresse }} dans la liste. Reconnectez-vous, puis recliquez sur le lien de l'étape 1.
    C'est le piège le plus fréquent. Google bascule souvent tout seul vers le dernier compte utilisé, et le mot de passe créé sur le mauvais compte ne fonctionnera jamais ici.
  3. Si un robot cassé s'affiche avec « Ce paramètre n'est pas disponible » : il manque la validation en deux étapes sur ce compte. Google masque entièrement la page tant qu'elle n'est pas activée.
    Ouvrez la validation en deux étapes et descendez tout en bas de la page. Un bouton bleu s'y trouve :
    • Il dit « Activer la validation en deux étapes » → cliquez. Google demandera votre mot de passe habituel, puis un numéro de téléphone, et vous enverra un code par SMS à recopier.
    • Il dit « Désactiver » → c'est déjà en service. Revenez à l'étape 1.
    Ne vous fiez pas au reste de la page : un téléphone déjà vérifié ou une clé d'accès présente ne veulent pas dire que la validation est enclenchée. Seul le bouton du bas dit la vérité.
  4. Créez le mot de passe. Sur la page des mots de passe, un champ vide porte la mention grise « Nom de l'appli ». Tapez-y DFM, puis cliquez sur Créer. Ce nom ne sert qu'à vous : c'est ainsi que vous reconnaîtrez ce mot de passe si vous voulez le supprimer plus tard.
  5. Copiez les 16 lettres. Google les affiche en gros, dans un cadre, groupées par quatre. Sélectionnez-les et copiez-les, puis collez-les dans le champ ci-dessous.
    Les espaces n'ont pas d'importance, ils sont retirés automatiquement. Ne fermez pas la fenêtre avant d'avoir collé : Google ne les affiche qu'une seule fois. Si elle se ferme trop tôt, supprimez le mot de passe « DFM » et recommencez l'étape 4 — ce n'est pas grave.
{% elif envoi.f.special == 'microsoft' %}
Votre adresse est chez Microsoft
  1. Microsoft exige lui aussi un mot de passe d'application, et la validation en deux étapes activée sur le compte.
  2. Rendez-vous sur la sécurité de votre compte Microsoft, activez la validation en deux étapes si ce n'est pas fait, puis créez un mot de passe d'application.
  3. Collez-le ci-dessous.
Microsoft ferme progressivement l'envoi par mot de passe sur les comptes personnels. Si l'essai échoue malgré un mot de passe correct, c'est probablement cette raison — et il faudra une adresse ailleurs.
{% elif envoi.f.special == 'yahoo' %}
Votre adresse est chez Yahoo
  1. Yahoo exige un mot de passe d'application, créé depuis les paramètres de sécurité de votre compte.
  2. Collez-le ci-dessous.
{% elif envoi.f.connu %}
Votre adresse est chez {{ envoi.f.nom }} — une minute
  1. Saisissez ci-dessous le mot de passe de la boîte {{ envoi.adresse }}, celui avec lequel vous relevez votre courrier. Pas de manipulation particulière chez {{ envoi.f.nom }} : aucun « mot de passe d'application » à créer.
  2. Le serveur d'envoi est déjà connu : {{ envoi.f.serveur }}.
{% else %}
Votre adresse est sur votre propre domaine
  1. Laissez DFM chercher le serveur. Cliquez sur Trouver automatiquement ci-dessous : DFM interroge {{ envoi.f.domaine or "votre domaine" }} pour savoir qui héberge son courrier, puis vérifie que le serveur répond. Cette information est publique et inscrite dans votre domaine. Vous n'avez rien à demander à personne.
  2. Saisissez le mot de passe de la boîte {{ envoi.adresse }} — celui avec lequel vous relevez votre courrier.
  3. Enregistrez. DFM envoie aussitôt un mail d'essai et vous dit si tout fonctionne.
Chez la plupart des hébergeurs, le mot de passe de la boîte suffit — aucun « mot de passe d'application » à créer. Cette notion est propre à Google, Microsoft et Yahoo.

Si la recherche ne trouve rien, votre hébergeur nomme son serveur d'une façon inhabituelle. Cherchez alors dans son aide en ligne « configurer un logiciel de messagerie » — le serveur d'envoi y figure, sous le nom SMTP.
